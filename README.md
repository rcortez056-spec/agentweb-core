# agentweb-core

An open-source browser-based agent network runtime conforming to the open agentic web specification.

## Overview
`agentweb-core` is a lightweight, zero-latency browser runtime and agent networking layer designed to run natively within standard web browsers without requiring third-party server backends.

## Specification & Conformance
This repository provides the conforming `.json` agent network file, browser runtime, and interface files required by the Open Agentic Web Challenge.
